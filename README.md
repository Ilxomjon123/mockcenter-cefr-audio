# mockcenter-cefr-audio

Listening audio for MockCenter CEFR Multilevel practice tests, one file per part:
`full_mock_N/part_1.mp3 … part_6.mp3` and `test_N/part_1.mp3 … part_6.mp3`.

Served to the exam app via `https://raw.githubusercontent.com/Ilxomjon123/mockcenter-cefr-audio/main/<path>`.
Do not rename or move files: the MockCenter database stores these URLs.
